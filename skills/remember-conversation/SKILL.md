# Remember a conversation

Store only context that can improve a future conversation.

## Process

1. Extract durable facts, decisions, commitments, preferences, and relationship context. Exclude greetings, repetition, speculation presented as fact, credentials, and details with no likely future value.
2. Search existing people before creating or linking anyone. Ask when identity remains ambiguous.
3. Search existing sources for the same conversation or meeting. Update a matching external source when stable provider, id, and version values exist. Otherwise create one clearly titled source.
4. Link person-specific context to the matching people. Keep general knowledge global.
5. Show the concise handoff content and target records before writing.
6. Report the created or updated source and people links. Never claim content was saved unless SynTwin confirms it.

Do not send messages, change rooms, or broaden the task beyond remembering the conversation.
